The one question the final system answers

A user types a business initiative. The system answers: which tasks does it involve, and which skills are needed?

Both lists come with supporting job postings as proof. To get there, each section first builds a taxonomy: a tidy tree of all tasks (A) or all skills (B) found in real job postings.

What is a taxonomy?A tree that groups similar things. Example: Skills → Software → Programming languages → Python. We build it from the bottom (thousands of skill phrases) to the top (a few big groups).
