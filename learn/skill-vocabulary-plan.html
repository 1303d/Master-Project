Skill Vocabulary Plan

An open, growing skill list for our gold set, linked to ESCO. No 500 limit, and labels are never forced into a list.

The problem: three people write the same skill three ways ("MS Excel", "Microsoft Excel", "Excel"). Scoring then counts correct answers as wrong.
The fix: label freely, then clean the names and link each one to ESCO automatically. People check only the doubtful ones.
