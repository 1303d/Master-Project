The idea: similar skills sit close together

Each skill becomes a list of 384 numbers (an embedding). Skills with similar meanings get similar numbers, so they sit close together in this "meaning space". Clustering finds the crowded areas. Each crowded area is a topic.

This is a toy picture in 2D. The real points are in 384D. We squash them to 10D with UMAP before HDBSCAN, and to 3D only for the Skill map tab.

Stability (AMI across 80% subsets, higher = steadier)

AMI = adjusted mutual information: 1 means two runs agree fully, 0 means they agree only by chance. Per-topic Jaccard = for each topic, how much of it survives in the other run (median). Coverage = share of skills that get a topic. HDBSCAN's AMI is measured only on the 78% of skills it clusters, so it looks better than it is.

The skill library: skills that are everywhere

Some skills ("communication", "teamwork", "excel") appear in every sector. They do not belong to one topic. Many of them end up as HDBSCAN noise. So we built a library: a label on a skill (not a new id) that says "this skill is cross-sector".

Rule library-v1 (a skill enters the library when all three are true):
  1. It appears in at least 5 postings.
  2. It appears in at least 4 of the 8 sectors.
  3. Its top sector has at most 50% of its postings (no single sector owns it).
Status confirmed = at least 10 postings, otherwise candidate. Spread is also scored with entropy.
Result: 197 library skills (148 confirmed). Tools such as excel, word and power bi stay in the library (your decision). 45 topics are flagged transversal (soft-skill topics). The Skill map tab colours only the top-20 domain topics.

Links: which topics does a library skill go with?

For each library skill and each topic, we count postings that have both. A hypergeometric test gives a p-value. We correct the p-values for the full family of 67,501 pairs with BH (FDR) → q-value.

Strong link = at least 5 shared postings, lift ≥ 1.5, q < 0.05. Others are weak. Result: 985 links, 272 strong. On the Skill map, click a library skill: thick lines = strong, thin = weak.
